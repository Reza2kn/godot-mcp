# Support policy

- Node.js: 18, 20, and 22.
- Godot: 4.3 through 4.6 are tested in CI; newer Godot 4.x versions are tested
  before release and supported when the compatibility job passes.
- Operating systems: macOS, Linux, and Windows server paths are implemented;
  release acceptance currently runs on macOS and Linux.

Bug reports should include the Godot version, Node version, operating system,
MCP client, discovery-mode setting, relevant tool call, structured error, and a
minimal disposable project when possible.
